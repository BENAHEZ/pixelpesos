# Pixel Pesos

Videojuegos y tecnología, con precio en pesos.

Este repositorio contiene **solo el sitio ya construido** que publica Cloudflare Pages. No se edita a mano:
el código fuente, las notas y el generador viven en el segundo cerebro (`PROYECTOS/sitio-noticias/` del
repo `BENAHEZ/segundo-cerebro`) y se copian aquí con `publicar.sh`.

**Cloudflare Pages:** Framework preset *None*, Build command vacío, Build output directory `/`.
